# 构建与运维手册

## 1. 适用对象

本文档面向开发同学、测试同学、发布同学和运维同学，说明如何构建、运行、部署、查看日志以及做基础排障。

## 2. 构建命令

### 2.1 运行测试

```powershell
mvn test
```

### 2.2 打包构建

```powershell
mvn clean package
```

产物默认位于：

```text
target/file-transfer-system-0.0.1-SNAPSHOT.jar
```

### 2.3 本地启动 JAR 包

```powershell
java -jar target/file-transfer-system-0.0.1-SNAPSHOT.jar
```

## 3. 启动前检查

启动前应确认：

- JDK 版本为 21 或以上
- 运行用户对源/目标目录有权限
- `transfer.temp-dir` 目录可创建、可写
- 数据库路径可写
- 如果启用 Redis，网络连通且认证配置正确

## 5. 日志规范

日志配置文件位于 [logback-spring.xml](/C:/Users/小楠同学/Documents/demo/src/main/resources/logback-spring.xml:1)。

### 5.1 输出位置

- 控制台
- `./logs/file-transfer-system.log`
- `./logs/archive/` 按日期和大小滚动归档

### 5.2 单条日志字段

- 时间
- 级别
- 线程名
- `requestId`
- logger 名
- 消息正文
- 异常堆栈

### 5.3 推荐排障入口

排障时优先按以下维度搜索：

- `requestId`
- `taskId`
- `batchId`
- `recordId`

## 7. 常见运维场景

### 7.1 任务长时间停留在 `PLANNING`（规划中）

排查建议：

- 检查源目录是否极大或存在 IO 瓶颈
- 查看是否有规划失败日志
- 查看数据库是否写入缓慢

### 7.2 任务频繁进入 `FAILED`（失败）

排查建议：

- 查看 `lastError`
- 检查目标路径磁盘空间和权限
- 检查源文件是否被并发修改
- 如果是 `FULL_HASH`，关注哈希计算耗时和文件稳定性

### 7.3 背压频繁触发

排查建议：

- 查看 `metrics` 中的 `throttleReasonCounts`
- 调整并发度、批次大小、在途字节上限
- 排查磁盘吞吐或线程池容量不足

## 8. 发布建议

如果用于正式环境，建议额外补齐：

- 独立配置文件分环境管理
- 启动脚本或容器镜像
- PostgreSQL 外部数据库
- Flyway/Liquibase 数据库版本管理
- 日志采集接入 ELK / Loki / Splunk
- Prometheus 采集和告警配置
